# AI 前沿周报写作规范

每周一期的 AI 前沿快讯总结。本文是写每一期时的操作手册与格式约定。

## 快速开始

```bash
pnpm new:weekly
```

脚本会自动完成：扫描已有期号取最大值 +1、按今天日期算出覆盖区间（可交互修改）、创建文件、写好 frontmatter、用 VS Code 打开。**正文从空白开始写，其余不用手动填。**

---

## 文件与命名

| 项 | 约定 | 示例 |
|---|---|---|
| 目录 | `content/posts/weekly/<年份>/` | `content/posts/weekly/2026/` |
| 文件名 | `YYYY-MM-DD-issue-NNN.md` | `2026-08-20-issue-001.md` |
| 期号 | 三位补零，全局递增，不按年重置 | `001`、`012`、`137` |

**目录位置是硬边界。** 系统靠 `posts/weekly/` 这个路径前缀判断一篇文章是不是周报——决定它出现在 `/weekly`、进入 `/weekly.xml`、以及从首页文章流中排除。放错目录，改 frontmatter 也救不回来。

期号由脚本扫描 `content/posts/weekly/` 下**所有**文件名中的 `issue-(\d+)` 取最大值得出，所以跨年份目录也不会重号。

## Frontmatter

```yaml
---
title: "AI 前沿周报 #001（2026.08.13 - 08.19）"
description: DeepSeek 的一周三连击、国内 API 涨价潮终结白菜价时代、GLM-5.3 与 Qwen3.8-27B 的后训练突围。
date: 2026-08-20
updated: 2026-08-20
categories: [周报]
tags: [AI, 周报, DeepSeek, LLM, Agent]
type: weekly
---
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | ✅ | **必须用双引号包裹**，见下方「标题格式」。列表页的期号与区间从这里解析 |
| `description` | ✅ | 一句话概括本期主线。用于列表页 hover 提示、SEO 描述、RSS 摘要。建议 40–80 字，控制在一句话内 |
| `date` | ✅ | 发布日期。列表排序依据；标题缺区间时用它反推前 7 天。支持 `2026-08-20` 或 `2026-08-20 14:30:00` |
| `updated` | ✅ | 更新日期，初次发布与 `date` 相同 |
| `categories` | ✅ | 固定 `[周报]`。决定文章页的分类标签与配色 |
| `tags` | ✅ | 按本期内容调整，建议 4–6 个。`AI`、`周报` 建议固定保留 |
| `type` | ✅ | 固定 `weekly`。决定正文套用 `.md-weekly` 版式，**写错则所有排版优化失效** |

可选字段：`image`（封面图）、`draft: true`（草稿，不发布也不进 RSS）、`references`（参考链接列表）、`permalink`（自定义链接）。

> `recommend` 对周报无效——它是首页推荐轮播的抽样权重，而周报不进首页。

## 标题格式

```text
AI 前沿周报 #001（2026.08.13 - 08.19）
└── 固定前缀 ──┘ └期号┘ └──── 覆盖区间 ────┘
```

列表页会把它解析并重排成：**周报第 001 期 · 08.13 ~ 08.19**

**期号**：`#` + 三位数字。解析失败时列表退化显示完整标题。

**覆盖区间**：写在圆括号里，起止用分隔符连接。

- 括号：中文 `（）` 或英文 `()` 均可
- 分隔符：`-`、`–`、`—`、`~` 均可
- 日期：点分 `2026.08.13` 或斜杠 `2026/08/13` 均可
- 起始日期的年份会在列表页自动去掉，只显示 `08.13 ~ 08.19`

**区间可以省略**，此时列表页按 `date` 往前推 7 天自动计算（即「发布日之前的 7 天」）。但建议照写，因为标题里写明的区间在 RSS 和搜索结果里同样可见。

## 正文结构

正文结构**不固定**，按每期内容自由组织。以下是约定和会被特殊渲染的元素。

### 硬性约定

**不要写 `#` 一级标题。** 文章页已经渲染了 frontmatter 里的 `title`，正文再写一次会重复。

### 排版元素对照

| Markdown | 渲染效果 | 建议用法 |
|---|---|---|
| `## 一、大节标题` | 加大字号 + 底部分隔线 + 大留白 | 本期的主线板块 |
| `### 1. 小节标题` | 左侧主题色竖条 | 板块内的具体条目 |
| `- 列表项` | 加宽行距（1.9）与条目间距 | 正文主体 |
| `- **引子**：内容` | 首个粗体渲染为主题色 | 承担「这条讲什么」的小标题 |
| `---` | 极轻的分隔线 | 大节之间 |
| `> 引用` | 略小字号 | 引述原文 |
| `*斜体独占一段*` | 缩小、置灰 | 文末免责声明 |

**关于粗体**：列表项里的**首个**粗体是主题色纯文字；其他位置的粗体沿用全站的高亮底样式。周报里粗体密度高，建议只在需要强调的地方用，避免满屏高亮。

### 目录（TOC）

右侧目录自动收录 `##` 到 `####`。用 `##` / `###` 组织层级即可，不需要额外配置。

## 三个必须绕开的坑

### 1. YAML 会把 `#` 当注释

```yaml
title: AI 前沿周报 #001（2026.08.13 - 08.19）   # ❌ 标题被截成「AI 前沿周报」
title: "AI 前沿周报 #001（2026.08.13 - 08.19）" # ✅
```

空格后跟 `#` 在 YAML 中开启行内注释，后面全部丢失。**任何含 `#` 的字段都要加引号**，`description` 同理。

这个坑很隐蔽：期号丢了之后，区间会走 `date` 反推的兜底路径、结果往往碰巧正确，看起来只是期号不见了。

### 2. `$` 会被当成数学公式

```markdown
定价输入 $0.75/输出 $3.75    ❌ 两个 $ 之间被当作行内公式，中文报错、渲染错乱
定价输入 \$0.75/输出 \$3.75  ✅
定价输入 `$0.75`/输出 `$3.75` ✅ 用行内代码包裹也可以
```

一行里出现两个 `$` 就会触发。启动时控制台会报 `unicodeTextInMathMode` 警告，可以作为自查信号。

### 3. `::` 开头的行是组件语法

本项目用 MDC 语法，行首的 `::` 会被解析为组件块。正文里要写连续冒号时，用行内代码包裹。

## 发布前检查清单

- [ ] `title` 加了双引号，期号三位、区间格式正确
- [ ] `type: weekly`、`categories: [周报]` 没写错
- [ ] `description` 写了实质内容，不是模板占位符
- [ ] `tags` 按本期内容调整过
- [ ] 正文没有 `#` 一级标题
- [ ] 涉及金额的 `$` 已转义
- [ ] `pnpm dev` 启动无 KaTeX 警告
- [ ] `/weekly` 列表页显示为「周报第 NNN 期 · MM.DD ~ MM.DD」，期号不是 `—`
