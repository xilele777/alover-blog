# 徽章收藏柜

访问 `/badges`，或点击导航中的「徽章」。紧凑卡片居中显示名称和获得日期，分类标在图片区域右下角；点击从卡片位置展开 SVG 大图、详情与获得日期，关闭时收回。详情支持 Esc、关闭按钮或点击遮罩关闭，并适配系统的减少动态效果设置。

## 后台上传

1. 进入 `/admin`，完成现有 GitHub 配置，点击顶部「徽章」。
2. 点击「添加徽章」，上传 SVG，填写名称、获得日期和详情，可选填分类（最多 30 字，可复用已有分类）。SVG 最大 2 MB，可直接预览。
3. 点击「保存徽章到暂存区」，SVG 图片和徽章信息会一起进入现有暂存区，刷新后台后仍可继续编辑。
4. 点击「提交全部」，核对修改并提交。仓库构建部署完成后，前台页面和右侧统计自动更新。

支持替换 SVG、调整展示顺序和移除徽章。关闭管理窗口前请先保存到暂存区。移除徽章不会直接删除仓库里的图片，避免误删其他内容引用的资源；图片库的引用检测会包含徽章数据，可在确认无引用后清理。

上传文件会检查 SVG 格式，拒绝脚本、事件、嵌入网页、动画和外部资源。SVG 以图片方式展示，不将源代码注入页面。导出时建议保留 viewBox 并将图形资源嵌入 SVG。

## 数据与统计

- 数据文件：`data/badges.json`。
- SVG 目录：`public/images/badges/`。后台生成唯一文件名，避免覆盖已有图片。
- `data/badges.ts` 是读取和校验入口，不需要编辑。
- 右侧统计按三行展示已获得数量、分类数、最近获得日期。演示徽章不参与统计；未填写分类的正式徽章归入「未分类」，小卡片上不额外显示标签。分类只作标注和统计，不作筛选导航。卡片整体悬浮时保持静止，鼠标移到徽章图片上才触发徽章动效。

也可以直接在 JSON 数组中添加以下记录（图片需一并放入目录）：

```json
{
  "id": "my-badge",
  "name": "我的徽章",
  "image": "/images/badges/my-badge.svg",
  "description": "获得徽章的经过，以及它对我的意义。",
  "date": "2026-09-16",
  "category": "活动纪念"
}
```

除 category 选填外，上述字段均必填，id 必须唯一，日期为有效的 YYYY-MM-DD。占位徽章使用可选的 `demo: true` 标记。
